## What it means

The file is a program or contains programs. The most common types are:

- a program that installs or runs;
- a file of instructions (a script);
- a shortcut;
- a disk image, which is a file that works like a virtual disk.

## What the risk is

Opening it can run harmful programs on your computer. A shortcut can launch a hidden command. A disk image can carry programs that Windows does not watch in the same way.

## What to do

Do not open the file. People and companies rarely send this type of file by email.
