## What it means

The site name looks like the name of a well-known brand or contains it, but the site does not belong to that brand. It does so in one of these ways:

- it changes a letter;
- it uses a digit that looks like a letter;
- it uses another address ending;
- it puts the brand at the start of the address;
- it puts the brand next to other words.

## What the risk is

Whoever reads the message sees the brand name and assumes the site is theirs. The owner is shown by the site name, which is the last word before the ending, such as `.com`.

## What to do

Check which name it is. Go in through the official address of the company.

This check uses a list of brands and can flag a legitimate site with a similar name.
