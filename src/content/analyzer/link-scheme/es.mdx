## Qué significa

El enlace no apunta a una página web. Algunos tipos de enlace ejecutan código, como `javascript:` o `data:`. Otros abren otra aplicación del equipo, como `ms-msdt:` o `search-ms:`.

## Qué riesgo tiene

El tipo `ms-msdt:` abre la herramienta de diagnóstico de Windows. La vulnerabilidad Follina (CVE-2022-30190) estuvo en esa herramienta y se explotó de forma activa.

Un enlace `data:` o `javascript:` puede mostrar una página falsa o ejecutar código sin salir del mensaje.

## Qué hacer

No pulse el enlace. Un mensaje legítimo casi nunca usa estos tipos de enlace.
