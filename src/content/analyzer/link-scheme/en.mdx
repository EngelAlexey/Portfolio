## What it means

The link does not open a web page. Some links run instructions directly and others open a program on your computer.

## What the risk is

A link of this kind can show a fake page or run instructions without leaving the message. One of them, `ms-msdt:`, opens the Windows diagnostic tool. That tool had a serious flaw, called Follina, which attackers exploited.

## What to do

Do not click the link. A legitimate message almost never uses this type of link.
