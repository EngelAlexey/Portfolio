## What it means

The link does not point to a web page. Some types of link run code, such as `javascript:` or `data:`. Others open another application on your computer, such as `ms-msdt:` or `search-ms:`.

## What the risk is

The `ms-msdt:` type opens the Windows diagnostic tool. The Follina vulnerability (CVE-2022-30190) was in that tool and was actively exploited.

A `data:` or `javascript:` link can show a fake page or run code without leaving the message.

## What to do

Do not click the link. A legitimate message almost never uses these types of link.
