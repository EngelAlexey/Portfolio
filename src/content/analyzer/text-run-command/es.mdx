## Qué significa

El mensaje o una página le pide abrir una ventana de Windows con las teclas Windows y R (`Win+R`) o una terminal. Luego le pide pegar un texto y ejecutarlo. Esta técnica se llama ClickFix.

## Qué riesgo tiene

Un texto pegado así se ejecuta con sus permisos y pasa por encima de las defensas del navegador y del correo. Microsoft documentó esta técnica para instalar programas que roban información.

## Qué hacer

No pegue ni ejecute nada. Cierre la página.

Si ya lo hizo, desconecte el equipo de Internet y cambie sus contraseñas desde otro dispositivo.
