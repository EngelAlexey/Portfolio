## What it means

The link leads to the download of a file. By its name, it can be a program, a document with macros (automatic instructions inside the document) or a compressed file.

This analysis does not open the link, so it does not know which file the site delivers.

## What the risk is

A downloaded program can install harmful software when it is opened. A document with macros can run instructions when you click "Enable content". A compressed file can hide either of the two.

## What to do

Do not download the file from the message. If you expected it, ask the sender for it through another channel.

Office blocks macros in files that come from the Internet. Do not remove that block on a file you do not know.
