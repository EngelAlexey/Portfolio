## What it means

The file is not what its name suggests. It can happen in three ways:

- the name says one type of file and the content is another;
- the name has two endings, such as `invoice.pdf.exe`, and Windows can hide the last one;
- the name includes an invisible character that reverses the order of the letters, so the real ending looks like another.

This analysis looks at the content of the file and not only at its name.

## What the risk is

A program can pass as a document and run when it is opened. Attackers use this trick in email attachments.

## What to do

Do not open the file. If you expected it, ask the sender, through another channel, what it is called and what type it is.
